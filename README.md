## 🚀 Run Project Page

Create and activate a conda environment:

```bash
conda create -n talkgrpo python=3.10
conda activate talkgrpo
```

Install Flask:

```bash
pip install flask
```

Run the Flask app:

```bash
python app.py
```

Open the webpage in your browser:

```text
http://127.0.0.1:5000
```

The webpage loads videos and images dynamically from `data.json`.
